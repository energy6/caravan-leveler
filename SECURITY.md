# Security Policy

## Supported versions

Security fixes are made on the current development branch and, when practical,
the latest published release. Older releases are not guaranteed to receive
updates.

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in a public issue. Once the
repository is hosted on GitHub, use GitHub's private vulnerability reporting or
open a private security advisory. If that is unavailable, contact the repository
owner privately through their GitHub profile.

Include the affected version or commit, impact, reproduction steps, and any
suggested mitigation. Avoid including real Bluetooth addresses, credentials,
signing material, or other personal data.

You should receive an acknowledgement within seven days. The maintainer will
coordinate disclosure after a fix or mitigation is available.
